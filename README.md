# 🦷 Dental Clinic Queue & Reservation System

A web-based dental clinic management system with online appointment booking and real-time queue management.

## 🌐 Live Demo

| Portal | Link |
|--------|------|
| 🏠 **Patient Portal** (Public) | [antrigigi.vercel.app](https://antrigigiadmin.vercel.app/) |
| 👨‍⚕️ **Staff Portal** (Admin) | [antrigigiadmin.vercel.app](https://antrigigiadmin.vercel.app/) |

## 🚀 Features

### Patient
- Register & login with email verification
- Book appointments online
- View real-time queue status

### Admin / Staff
- Manage patient queue (walk-in & appointment)
- Create billing / invoice
- Manage doctor schedules
- Reset daily queue

## 🛠️ Tech Stack
- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: Next.js Server Actions, Prisma ORM
- **Database**: PostgreSQL (Supabase)
- **Auth**: JWT (custom), Email OTP verification
- **Deploy**: Vercel
